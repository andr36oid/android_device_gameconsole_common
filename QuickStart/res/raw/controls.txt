# Buttons and shortcuts: the one list behind Settings > Buttons and shortcuts
# (ControlsActivity) and its host check (tests/check-controls.py). Change a
# combination here, never in the Java code; the check compares every row with
# the key layout, the FN code, joyMouse and the seeded emulator settings.
#
# topic <string>            a topic in the list on the left
# heading <string>|=<name>  a heading on the page (=: a name, not translated)
# text <string>             a paragraph
# art <text>                one line of the console drawing (monospace)
# row <keys> = <string>     buttons and what they do. " + " joins buttons
#                           pressed together, " / " splits alternatives.
#                           @name is a string of this app (e.g. @key_dpad),
#                           a + or - right after it is kept (@key_volume+).
# Indented lines belong to the item above:
#   if-package <pkg>        only when the app is installed
#   if-file <path>          only when the file exists (a seeded setting)
#   if-prop <prop>          only when the property is true
#   check ...               for the host check only (see check-controls.py)
# A condition on a topic or heading hides everything up to the next one.
# A topic without a single row left is hidden.
