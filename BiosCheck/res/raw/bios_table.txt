# BIOS files for the emulators andr36oid ships (emulators/cores.lock, apks.lock).
#
# Sources:
#  - file names and which core loads which: libretro-core-info (firmwareN_path,
#    github.com/libretro/libretro-core-info, *_libretro.info), checked against each
#    core's source at the commit in cores.lock
#  - MD5s: libretro-database dat/System.dat (github.com/libretro/libretro-database,
#    commit d5bae90b), which the core info notes and the libretro docs quote too
#  - "*" instead of MD5s: no single known-good file (Neo Geo's neogeo.zip differs
#    between arcade core versions), so any file with this name counts
#  - a name with a slash is in that subfolder of the bios folder (neocd/...); a name
#    ending in a slash is a folder that has to be there (blueMSX's Machines/)
#  - left out on purpose: add-on hardware nobody plays here (Fuse's Pentagon and
#    Scorpion ROMs, VICE's JiffyDOS, the 64DD IPL, BS-X / Sufami Turbo), and FBNeo's
#    other arcade BIOS sets (they go next to the games like neogeo.zip). No BIOS at
#    all: Game & Watch, Virtual Boy, ZX Spectrum (Fuse has its ROMs built in), C64
#    (VICE too), Vectrex, DOSBox Pure, PrBoom (prboom.wad goes next to the WADs),
#    FAKE-08.
#
# Everything goes right into the bios folder on EASYROMS, which is RetroArch's system
# folder (gameconsole-emu sets system_directory). PPSSPP needs no BIOS.
#
# system|<id>|<name>|<cores, space separated>|<shown: shipped = always, installed =
#       only when one of its cores is installed>|<note>
# file|<system id>|<file name>|<required, oneof (one of these is enough) or optional>|
#     <MD5s, space separated, or *>|<what it is>|<cores that use it, empty = the system's>
